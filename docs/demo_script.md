# Build plan and demo script

## The 60-minute build

| Minutes | Do this | Done when |
| --- | --- | --- |
| 0–5 | Adjust the problem line to anything new from the evening's talks | Problem fits in one sentence |
| 5–20 | Create the agent, paste the prompt, attach the voice, set the first message | It runs step 1 end to end |
| 20–35 | Run the full protocol 3 times; fix skipping, rambling, or ignoring "止めて" | All 6 steps + summary in under 3 minutes |
| 35–45 | Add one ElevenCreative extra: chime, alert tone, or 10-second title clip | One asset ready |
| 45–50 | Record a backup walkthrough | Saved to `recordings/` |
| 50–60 | Rehearse the pitch twice | Under 2 minutes |

## The 2-minute pitch

1. **Problem (20 s)** — "Labs and robotics companies in Japan want international talent, but day-one training and safety briefings are usually Japanese-only. New hires feel lost, and managers hesitate to hire."
2. **Solution (10 s)** — "LabScout Voice is a bilingual lab buddy that talks a new hire through each protocol step and waits for them to confirm."
3. **Live demo (60 s)** — Steps 1–2 answering "完了", one English question, then "止めて" to show the emergency stop.
4. **How it was built (15 s)** — "ElevenAgents and Voice Design. The steps come from my LabScout protocol file, the same one behind my robot dog dashboard and future smart-glasses display."
5. **Next step (15 s)** — "Next, the same voice speaks alerts through Even Realities glasses and guides robot-dog and robot-arm tasks, always with human confirmation."
